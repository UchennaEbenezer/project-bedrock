4. Deployment & Operations

How to run the pipeline

  • The CI/CD pipeline is handled by GitHub Actions (.github/workflows/terraform-ci-cd.yml).
  • Any push or merge to the main branch automatically runs formatting validations and applies the Terraform code.
  • The pipeline connects to AWS using repository secrets AWS_ACCESS_KEY_ID and AWS_SECRET_ACCESS_KEY.

Running Retail Store URL

The Application Load Balancer routes external traffic directly to the UI frontend:
